## 🛠️ Technologies Utilisées

- **HTML5 sémantique** optimisé pour le référencement naturel (SEO & Open Graph).
- **CSS3 moderne (Vanilla)** : variables CSS, *glassmorphism*, animations fluides, typographies Google Fonts (*Cormorant Garamond* et *Plus Jakarta Sans*).
- **JavaScript Vanilla ES6+** sans dépendance lourde, garantissant des temps de chargement ultra-rapides.

## 🚀 Démarrage Rapide

Ouvrez simplement `index.html` dans votre navigateur ou lancez un serveur local :

```bash
# Avec Python 3
python3 -m http.server 8088

# Ouvrir dans le navigateur
open http://localhost:8088
```
